# Panaflauge Federal Logistics LLC Landing Page

This is the demo landing page for `panaflauge360.com`.

## What Is Included

- Premium one-page landing page
- AI-generated hero and specimen-transport visuals
- Routine, STAT, and specialized courier service sections
- Quote request form configured for Netlify Forms
- Click-to-call buttons for urgent STAT requests
- Basic SEO metadata, sitemap, robots file, and local business schema
- Thank-you page after quote submission

## Before Publishing

1. Publish the folder to Netlify.
2. Point `panaflauge360.com` to the Netlify site.
3. In Netlify, open Project configuration > Notifications > Emails and webhooks > Form submission notifications and add an email notification for the `quote-request` form to `Panaflauge360@gmail.com`.
4. Submit the form once after launch and confirm the submission appears under Forms in Netlify.
5. Replace the current service area with a broader list if Teri wants to target specific nearby cities or states.

## Demo Preview

The site can be previewed locally from this folder with any simple static-file server.
