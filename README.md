# Panaflauge Federal Logistics LLC Landing Page

This is the demo landing page for `panaflauge360.com`.

## What Is Included

- Premium one-page landing page
- AI-generated hero and specimen-transport visuals
- Routine, STAT, and specialized courier service sections
- Quote request form connected to `Panaflauge360@gmail.com` through FormSubmit
- Click-to-call buttons for urgent STAT requests
- Basic SEO metadata, sitemap, robots file, and local business schema
- Thank-you page after quote submission

## Before Publishing

1. Publish the folder to the hosting provider.
2. Point `panaflauge360.com` to that hosting provider.
3. Submit the form once after launch. FormSubmit may send an activation email to `Panaflauge360@gmail.com`; confirm it so future quote requests deliver properly.
4. Replace the current service area with a broader list if Teri wants to target specific nearby cities or states.

## Demo Preview

The site can be previewed locally from this folder with any simple static-file server.
